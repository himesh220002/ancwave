## 4. Handling the Three User Traffic Conditions

```
                                  TRAFFIC STATE ENGINE
                                          │
       ┌──────────────────────────────────┼──────────────────────────────────┐
       ▼                                  ▼                                  ▼
[CONDITION A: THE FLOOD]       [CONDITION B: AIRPLANE LIVE]       [CONDITION C: ZERO-TRAFFIC]
  • Spatial Clustering           • Engagement Notifications         • Programmatic Pre-loading
  • Duplicate Merging            • Verified Freshness Timestamps    • Scraped Public Vacancies
  • Upvote-Priority Queue        • WhatsApp Ping Webhooks           • Municipal Tender Data
```

### Condition A: The Flood State (Citizens flooding the app with thousands of complaints)
- **Spatial Clustering (Supercluster / Mapbox):** Instead of crashing mobile browsers with 2,000 overlapping pins in one ward, the map collapses pins within a 200m radius into a single pulsing **"High-Urgency Cluster"**.
- **Upvote Deduplication:** If a citizen clicks *Report Pothole* in an already-flagged zone, the UI displays: *"Is this the same issue reported 2 hours ago?"* Clicking **Yes** converts their report into an **Upvote & Frequency Boost**, elevating the issue’s ranking rather than duplicating records.

### Condition B: The Airplane Live-View State (Passive, low-interaction browsing)
- **Passive-to-Active Hooks:** Passive observers who explore the map can hit *"Follow My Ward"* or *"Track This Issue"* to receive push/WhatsApp updates whenever status transitions occur.
- **Verified Freshness Timestamps:** Live badges (e.g., *"Verified by 14 local residents 8 mins ago"*) signal that the platform is vibrant, encouraging continuous return visits.

### Condition C: The Zero-Traffic State (Cold start with zero initial citizen submissions)
- **Pre-Loaded Government Data:** On Day 1, the platform is pre-populated using automated scrapers:
  - Open recruitment circulars for local district jobs, police constables, and railway apprentice posts.
  - Public budget allocations (e.g., *"₹65 Lakhs allocated for Ward 7 drainage — Tender passed 14 months ago — Ground Status: Inactive"*).
- **Instant Curiosity:** A user opening the app immediately sees actionable civic intelligence about their street even before anyone files a new report.

## 6. The State Machine & The 3-Day Engagement Loop

Every issue on the platform operates as a deterministic finite state machine, preventing false closures while imposing structural urgency on unresponsive authorities.

```
               [Citizen Submits Issue]
                          │
                          ▼

             │   (Problem Reported)    │                          │
             └─────────────────────────┘                          │

     Submits Proof        │ Neglect Counter ++                    │ Reverts

             ┌─────────────────────────┐                          │
             │    STATE 2: BLUE DOT    │                          │

                          │                                       │
             Citizens Flag│ Inactivity                            │
                          ▼                                       │
             ┌─────────────────────────┐                          │
             │   STATE 3: YELLOW DOT   │ ─────────────────────────┘
             │     (Work Delayed)      │
             └─────────────────────────┘
                          │
                          ▼
             ┌─────────────────────────┐
             │     HEATMAP NEGLECT     │
             │ (Crimson Urgency Aura)  │
             └─────────────────────────┘
```

### State Definitions:
1. **Red Dot (Not Started):** Baseline state created upon verification.
   - **The 72-Hour / 3-Day Ping Loop:** Every 3 days, reporters and upvoters receive a notification: *"Has the administration acted on this yet?"*
   - Clicking **"Still Ignored"** increments `neglectCounter` by +1, escalating the issue's position in regional priority feeds.
2. **Blue Dot (Solution In Progress):** Triggered when contractors or municipal workers begin field action.
   - **Verification Safeguard:** Transitioning to Blue requires an upload of photographic evidence (machinery on site, active workers, or official signed work orders).
3. **Yellow Dot (Delayed):** Triggered if a Blue Dot remains inactive for over 14 days without verifiable progress, or if local residents vote that workers abandoned the site unfinished.
   - Automatically restarts the 72-hour citizen auto-ping escalation cycle.

## 8. The Crowdsourced Moderation & Consensus Algorithm

To remove human moderation bottlenecks while preventing malicious spam or politically motivated fake reporting, the platform relies on **deterministic community consensus math**.

```
                        [Issue Submitted by User A]
                                     │
                                     ▼
                          Total Votes >= 50?
                             ├── Yes ──> [STATUS: TRUE (Published)]
                             └── No ──> Check Disputed Flags
                                           │
                        ┌──────────────────┴──────────────────┐
                  False Votes < 5                       False Votes >= 5
                        │                                     │
           [STATUS: TRUE (Provisional)]             (True - False) >= 20?
                                                       ├── Yes ──> [STATUS: TRUE]
                                                       └── No  ──> [STATUS: FALSE / PENDING]
```

### Mathematical Rules:
- **Rule 1 (Trust Threshold - 50+ Votes):** If an issue receives 50+ total votes, it is marked `True` immediately, as coordinating 50 unique physical citizens across a verified block is statistically robust.
- **Rule 2 (Provisional Pass):** If `falseVotes < 5`, the ticket is displayed provisionally to ensure real-time visibility.
- **Rule 3 (Dispute Delta - +20 Margin):** If 5 or more local accounts flag an entry as `False`, the item is hidden or flagged as *Disputed* unless verified supporters exceed dissenters by at least 20 votes (`trueVotes - falseVotes >= 20`).
- **Geofenced Balloting:** A user can only vote if their active device GPS falls within the geofenced boundary of that block/ward.
- **30-Day Rolling Window:** Issues retain active voting status for 30 days before archiving or escalation.

## 9. Split-Path 'Create Issue' Workflow & Geolocation Architecture

To capture physical damage (potholes, garbage) as well as non-physical or risky incidents (theft, bribery, harassment) where pointing a camera is impossible or unsafe, the creation flow splits into two distinct paths:

```
                          [Create Issue Button]
                                    │
                  ┌─────────────────┴─────────────────┐
                  ▼                                   ▼
        [PHOTO CAPTURE PATH]                [BLANK / WITNESS PATH]
     • Native In-App Camera              • Camera Optional / Omitted
     • Hardware GPS Locked On Click      • Instant Hardware GPS Silent Lock
     • Direct S3 Upload via Pre-Signed   • Marked as "Witness Dependent"
     • Disables Manual Pin Dragging      • Higher Verification Margin Required
```

### Security & Integrity Rules:
1. **Anti-Spoofing GPS Lock:** The device coordinates are obtained at the exact second the camera shutter or creation button is triggered. Users cannot upload photos from their phone gallery or manually drag pins across the map.
2. **Immutable Community Evidence:** Once a ticket is submitted and receives community votes, the original creator **cannot** delete it, preventing local bullies or corrupt contractors from coercing complainants into withdrawing reports.
3. **Geofenced Real-Time Chat Rooms:** Each ticket opens an isolated WebSocket/Socket.io discussion channel restricted to verified residents of that block, allowing neighbors to coordinate action anonymously (e.g. `Citizen_Ward4_X9`).

### A. Geotagged Camera Capture Component (`CameraCapture.tsx`)
```tsx
// components/CameraCapture.tsx
'use client';

import React, { useRef, useState } from 'react';
import { Camera, MapPin, AlertCircle, CheckCircle } from 'lucide-react';

interface LocationCoords {
  latitude: number;
  longitude: number;
  accuracy: number;
}

interface CameraCaptureProps {
  onCaptureComplete: (blob: Blob | null, coords: LocationCoords, isBlank: boolean) => void;
}

export const CameraCapture: React.FC<CameraCaptureProps> = ({ onCaptureComplete }) => {
  const videoRef = useRef<HTMLVideoElement>(null);
  const [coords, setCoords] = useState<LocationCoords | null>(null);
  const [streamActive, setStreamActive] = useState<boolean>(false);
  const [error, setError] = useState<string>('');

  const acquireAccurateLocation = (): Promise<LocationCoords> => {
    return new Promise((resolve, reject) => {
      if (!navigator.geolocation) {
        reject(new Error('Geolocation not supported by device hardware.'));
        return;
      }
      navigator.geolocation.getCurrentPosition(
        (position) => {
          const loc: LocationCoords = {
            latitude: position.coords.latitude,
            longitude: position.coords.longitude,
            accuracy: position.coords.accuracy,
          };
          setCoords(loc);
          resolve(loc);
        },
        (err) => {
          setError('Location permissions are mandatory for tamper-proof verification.');
          reject(err);
        },
        { enableHighAccuracy: true, timeout: 12000, maximumAge: 0 }
      );
    });
  };

  const startCamera = async () => {
    try {
      setError('');
      await acquireAccurateLocation();
      const stream = await navigator.mediaDevices.getUserMedia({
        video: { facingMode: 'environment', width: { ideal: 1920 }, height: { ideal: 1080 } },
        audio: false,
      });
      if (videoRef.current) {
        videoRef.current.srcObject = stream;
        setStreamActive(true);
      }
    } catch (err: any) {
      setError(err.message || 'Unable to access hardware camera feed.');
    }
  };

  const handleCapturePhoto = () => {
    if (!videoRef.current || !coords) return;
    const canvas = document.createElement('canvas');
    canvas.width = videoRef.current.videoWidth;
    canvas.height = videoRef.current.videoHeight;
    const ctx = canvas.getContext('2d');
    if (ctx) {
      ctx.drawImage(videoRef.current, 0, 0, canvas.width, canvas.height);
      canvas.toBlob(
        (blob) => {
          if (blob) {
            // Stop media stream tracks
            const stream = videoRef.current?.srcObject as MediaStream;
            stream?.getTracks().forEach((track) => track.stop());
            setStreamActive(false);
            onCaptureComplete(blob, coords, false);
          }
        },
        'image/jpeg',
        0.88
      );
    }
  };

  const handleSkipPhotoForCrimeOrSafety = async () => {
    try {
      const lockedCoords = coords || (await acquireAccurateLocation());
      onCaptureComplete(null, lockedCoords, true);
    } catch (err: any) {
      setError('Cannot proceed without GPS verification lock.');
    }
  };

  return (
    <div className="bg-zinc-900 border border-zinc-800 rounded-2xl p-5 text-white max-w-lg mx-auto shadow-2xl">
      <div className="relative aspect-video bg-black rounded-xl overflow-hidden border border-zinc-700/50 flex items-center justify-center">
        <video
          ref={videoRef}
          autoPlay
          playsInline
          className={`w-full h-full object-cover ${streamActive ? 'block' : 'hidden'}`}
        />
        {!streamActive && (
          <div className="text-center p-6 space-y-2">
            <Camera className="w-10 h-10 text-zinc-500 mx-auto" />
            <p className="text-xs text-zinc-400">Camera offline. Initialise to log photographic proof.</p>
          </div>
        )}
      </div>

      {coords && (
        <div className="mt-3 flex items-center gap-2 text-xs font-mono text-emerald-400 bg-emerald-950/40 border border-emerald-800/50 rounded-lg p-2.5">
          <CheckCircle className="w-4 h-4 shrink-0" />
          <span>
            GPS Lock: {coords.latitude.toFixed(5)}°, {coords.longitude.toFixed(5)}° (±{coords.accuracy.toFixed(1)}m)
          </span>
        </div>
      )}

      {error && (
        <div className="mt-3 flex items-center gap-2 text-xs text-red-400 bg-red-950/40 border border-red-800/50 rounded-lg p-2.5">
          <AlertCircle className="w-4 h-4 shrink-0" />
          <span>{error}</span>
        </div>
      )}

      <div className="mt-4 flex flex-col sm:flex-row gap-3">
        {!streamActive ? (
          <button
            type="button"
            onClick={startCamera}
            className="flex-1 py-2.5 px-4 rounded-xl bg-blue-600 hover:bg-blue-500 font-semibold text-xs tracking-wide transition-all shadow-lg"
          >
            Activate Live Camera
          </button>
        ) : (
          <button
            type="button"
            onClick={handleCapturePhoto}
            className="flex-1 py-2.5 px-4 rounded-xl bg-emerald-600 hover:bg-emerald-500 font-semibold text-xs tracking-wide transition-all shadow-lg"
          >
            Capture Verified Issue
          </button>
        )}

        <button
          type="button"
          onClick={handleSkipPhotoForCrimeOrSafety}
          className="py-2.5 px-4 rounded-xl bg-zinc-800 hover:bg-zinc-700 text-zinc-300 font-medium text-xs tracking-wide transition-all border border-zinc-700"
        >
          Omit Photo (Safety/Crime)
        </button>
      </div>
    </div>
  );
};
```

export const generateIssuePresignedUrl = async (req: Request, res: Response) => {
  try {
    const { blockId, latitude, longitude } = req.body;

    if (!blockId || !latitude || !longitude) {
      return res.status(400).json({ error: 'Missing mandatory geographic verification tags.' });
    }

    const uniqueId = crypto.randomBytes(16).toString('hex');
    const key = `issues/${blockId}/${Date.now()}-${uniqueId}.jpg`;

    const command = new PutObjectCommand({
      Bucket: process.env.AWS_S3_BUCKET_NAME!,
      Key: key,
      ContentType: 'image/jpeg',
      Metadata: {
        'geo-latitude': String(latitude),
        'geo-longitude': String(longitude),
        'geo-block': String(blockId),
      },
    });

    // 5-minute pre-signed upload URL
    const uploadUrl = await getSignedUrl(s3Client, command, { expiresIn: 300 });

    res.status(200).json({
      uploadUrl,
      fileKey: key,
      cdnUrl: `https://${process.env.CLOUDFRONT_DOMAIN}/${key}`,
    });
  } catch (err: any) {
    console.error('AWS Pre-Sign Error:', err);
    res.status(500).json({ error: 'Failed to configure secure AWS upload pipe.' });
  }
};

      supplementaryUploads: [{ type: String }],
    },
    status: {
      type: String,
      enum: ['not_started', 'in_progress', 'delayed'],
      default: 'not_started',
      index: true,
    },
    isWitnessDependent: { type: Boolean, default: false },
    neglectCounter: { type: Number, default: 0 },
    lastPingedAt: { type: Date, default: Date.now },
    reportedBy: { type: Schema.Types.ObjectId, ref: 'User', required: true },
    votes: [
      {
        userId: { type: Schema.Types.ObjectId, ref: 'User' },
        voteType: { type: String, enum: ['true', 'false'] },
        updatedAt: { type: Date, default: Date.now },
      },
    ],
    moderationStatus: { type: String, enum: ['true', 'false'], default: 'true' },
    assignedOfficials: {
      wardOfficer: { name: String, contact: String, image: String },
      mla: { name: String, contact: String, image: String },
    },
  },
  { timestamps: true }
);

IssueSchema.index({ location: '2dsphere' });

// Pre-save consensus validation hook
IssueSchema.pre('save', function (next) {
  const issue = this as any;
  if (!issue.isModified('votes')) return next();

  const trues = issue.votes.filter((v: IVote) => v.voteType === 'true').length;
  const falses = issue.votes.filter((v: IVote) => v.voteType === 'false').length;
  const total = trues + falses;

  // Rule 1: 50+ total voters establish unquestionable truth
  if (total >= 50) {
    issue.moderationStatus = 'true';
  }
  // Rule 2: Low-dispute baseline pass
  else if (falses < 5) {
    issue.moderationStatus = 'true';
  }
  // Rule 3: High dispute demands +20 margin
  else if (trues - falses >= 20) {
    issue.moderationStatus = 'true';
  } else {
    issue.moderationStatus = 'false';
  }

  next();
});

export default mongoose.model<IIssue>('Issue', IssueSchema);
